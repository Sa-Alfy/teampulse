Privacy policy

Last updated: October 3, 2026

Publisher: Shariar Ahamed

What it does

The extension reads the class announcements and assignments shown in your Microsoft Teams browser tabs and turns them into a briefing in the extension popup. It can open your classes or the Assignments app in your Teams tab when you use its sync or navigation controls.

Data it reads

From the Teams pages you are already viewing, including teams.microsoft.com, teams.cloud.microsoft, and the assignments frame at assignments.edu.cloud.microsoft, it reads class names, channel posts, author names, subjects, text, timestamps, attachment names, assignment titles, due dates, and status. It reads nothing on other websites.

Where data is stored

Scraped class names, announcements, assignment titles and dates, settings, and UI marks are stored in chrome.storage.local on your device. The temporary per-tab note of the open class is stored in chrome.storage.session and discarded when the tab closes. Data is not sent from the extension to a server.

What is never done

The extension makes no outgoing network requests. It has no server connection, analytics, tracking, ads, or remote code. It does not sell or share the data it stores. Links in Teams posts are only followed if you click them.

The extension is not affiliated with or endorsed by Microsoft or the university.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Optional self-host server

The repository includes a separate optional self-host server component for local data. It must be started separately, and this extension does not connect to it.

How to delete your data

Open the extension popup and select Clear stored data, or uninstall the extension. These actions delete the data stored by the extension.

This policy may be updated when the extension's behavior or declared permissions change. The date above identifies the current version.
